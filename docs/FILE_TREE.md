# LL5 File Tree

Annotated source tree of the ll5 monorepo. MCP server names use ll5- prefix (ll5-calendar, ll5-messaging) to avoid Claude Code SDK collisions.

**Dual run-variant [2026-07-10, UPDATED]:** opencode variant LIVE and operational on host (see `docs/opencode-variant-deployment.md`). Two interchangeable agent runtime variants (Claude Code + opencode). Gateway `agent-trigger.ts` is env-driven (no-op for Claude Code, HTTP POST for opencode with `model:{providerID:'opencode', modelID:deepseek-v4-pro}`). Agent container in compose parameterized by `AGENT_VARIANT` (host: `opencode`). Image: `ghcr.io/arnonzamir/ll5-run-opencode:latest` (self-contained CI build in variant repo). Model: `opencode/deepseek-v4-pro` via user's Zen API key (switched from free `deepseek-v4-flash-free` 2026-07-09). Container healthcheck fixed (proxy excluded), proxy crash fixed (headersSent guard). **2026-07-10 fixes:** (1) `agent-trigger-listener.ts` now only sends source metadata for external channels (whatsapp/telegram) — web/Android turns were being blocked by the external-authority-gate; (2) `anomaly-monitor.ts` narrative loop threshold raised 45m→90m for opencode's 60m cadence; (3) `stop-mirror.ts` fixed (was sending wrong field names to gateway — silently broken since deployment). **Feature parity:** 7 of 11 gaps vs Claude Code fixed. 3 low-priority gaps remaining.
