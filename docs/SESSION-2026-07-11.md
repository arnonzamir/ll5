## 2. THE OUTAGE — why the agent went silent, and the fix chain

Root causes stacked up; solved in order:

1. **deepseek reasoning models return EMPTY on large agent contexts.**
   `deepseek-v4-flash-free`/`-pro` spend the output budget on hidden reasoning →
   empty content (finish=length) → silent turns. Non-reasoning models (glm-5.2,
   minimax-m3, nemotron) produce content. **deepseek is unusable for this agent.**
2. **$62 monthly cap** on the `opencode` provider (`/zen/v1`) blocks all paid
   models. The "opencode-go" key is the SAME capped workspace on that endpoint.
3. **opencode-go is a DIFFERENT plan** at `https://opencode.ai/zen/go/v1` — NOT
   under the $62 cap, runs pro. Wired end-to-end (custom provider def in
   opencode.json, entrypoint auth per `OPENCODE_PROVIDER_ID`, orchestrator emits
   it). Switched to `opencode-go/glm-5.2` → worked.
4. **go plan has a WEEKLY quota** — hit it (resets ~weekly). Fell back to
   **`nemotron-3-ultra-free`** (free, uncapped, non-reasoning) — current model.
5. **Missing heartbeat**: opencode container never POSTed `/me/agent/heartbeat`
   → runtime drifted to `error` → routing misfired. Added a 60s heartbeat loop.
6. **Session churn**: ~12 debug re-provisions left stale opencode sessions;
   clean provisions fixed it. `noReply:true` in synthetic tests suppresses the
   reply (by design) — a testing artifact, not a bug.
7. **STALE LOCAL IMAGE**: `docker pull` on the host reported "up to date" without
   refreshing the `:latest` digest, so several re-provisions silently ran OLD
   builds ("the fix didn't take" moments). Fixed by force-remove + re-pull, and
   permanently by the orchestrator force-pull (§4).

## 3. Chat UX — inner voice folded, deterministic marker

- The agent's thinking (grounding briefs, "Processing…") flooded the thread as
  full bubbles (glm/nemotron put thinking in prose; Claude used thinking blocks).
- **`stop-mirror` `classifyMirror`** (variant `lib/mirror-classify.js`): folds
  inner voice to a dimmed `display_compact` row; only real answers are full
  messages. Honors `[[silent]]` (drop) / `[[compact]]`.
- **Deterministic `[[thinking]]` marker** (aliases `[[grounding]]`/`[[bg]]`): the
  persona instructs the agent to prefix ALL inner voice with it → folds
  deterministically; opener heuristic is the backstop.
- **Dashboard**: compact rows (inner voice AND tool calls) are now click-to-expand
  to full text. Android already had this + folds `display_compact` — no app change.
- Memory: `correction-capture` plugin durably stores corrections
  (`/internal/ingest-memory`); reactive full-grounding was tried and REVERTED (it
  spawned a grounder-per-turn recursion storm that wedged the agent).

## 4. Orchestrator force-pull (this change)

`DockerRuntime.provision` now `pullImage(spec.image)` before create — best-effort,
so a provision never silently runs a stale local `:latest`. Private GHCR image →
needs auth: `GHCR_PULL_TOKEN`/`GHCR_PULL_USER` (reuses the host's `GHCR_READ_PAT` +
`arnonzamir`, injected into `.env` by the deploy). Empty token → anonymous pull
fails → falls back to the local image (no regression).
